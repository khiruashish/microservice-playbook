# Chapter 1 code — Monolith vs SOA vs Microservices vs Modular Monolith

Docs: `docs/foundations/ch01-architecture-styles.md`

| Module | Band | What it shows | Port |
|---|---|---|---|
| `layered-monolith` | 🟢 L1 | Classic layered monolith; direct calls create temporal, code and deployment coupling | 8080 |
| `modular-monolith` | 🔵 L2 · 🟣 L3 · 🔴 L4 | Spring Modulith modules, enforced boundaries, events with a publication registry, and an extraction seam (in-process ⇄ HTTP) | 8080 |
| `kitchen-service` | 🔴 L4 | The kitchen capability extracted into its own service with the same contract | 8082 |

## Build and test (JDK 25, or JDK 21 with `-Djava.version=21`)

```bash
cd code
mvn -B -pl chapters/ch01-architecture-styles -am verify
```

## Run the extraction demo

```bash
# terminal 1 — the extracted kitchen
mvn -pl chapters/ch01-architecture-styles/kitchen-service spring-boot:run

# terminal 2 — the modular monolith, asking kitchen-service over HTTP
mvn -pl chapters/ch01-architecture-styles/modular-monolith spring-boot:run \
    -Dspring-boot.run.profiles=kitchen-remote

# terminal 3
curl -s -X POST localhost:8080/api/v1/orders -H 'Content-Type: application/json' -d '{
  "customerId": "cust-42", "restaurantId": "rest-biryani-house",
  "lines": [{"itemId": "dum-biryani", "name": "Hyderabadi Dum Biryani", "quantity": 2, "unitPricePaise": 34900}]
}' | jq

curl -s -X POST localhost:8082/api/v1/kitchens/rest-biryani-house/pause   # restaurant pauses → next order gets 409
# stop kitchen-service (Ctrl+C in terminal 1)                              # next order gets 503 + Retry-After
```

Module documentation (C4 and PlantUML diagrams) is generated by `ModularityTests` into
`modular-monolith/target/spring-modulith-docs`.
