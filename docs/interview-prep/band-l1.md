# L1 Questions (0–3 yrs)

<div class="badges" markdown><span class="badge badge-l1">L1 · Foundation</span></div>

At this level interviewers check that you can build and explain one service well. They ask what a microservice is and isn't, how REST maps to HTTP, what a health check is for, how a container differs from a VM, and why logs should be structured. They expect correct basics, not war stories.

**How to answer.** Define the term, give one concrete example, name one pitfall. "A readiness probe tells Kubernetes whether to send traffic; it shouldn't check the database, because then a database blip takes every pod out of the load balancer" is a complete L1 answer.

**Only 27 questions are marked L1**, because the chapters are written for practitioners and up. Pair this page with:

- [Your first microservice](../getting-started/first-microservice.md), which builds and explains one service end to end;
- the [glossary](../getting-started/glossary.md), whose 463 terms are the vocabulary L1 interviews test;
- the L1 learning path in [How to use this handbook](../getting-started/index.md#learning-paths);
- the [L2 questions](band-l2.md) on the communication and observability chapters, which are the next step up.
