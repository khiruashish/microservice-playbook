# L2 Questions (3–7 yrs)

<div class="badges" markdown><span class="badge badge-l2">L2 · Practitioner</span></div>

At this level interviewers check that you've built services that talk to each other and kept them running. Expect questions on HTTP clients and timeouts, REST design and errors, gRPC, Kafka consumers, transactions, caching, OAuth tokens, Testcontainers and Kubernetes basics, and on what you did when one of those went wrong.

**How to answer.** Mechanism, then trade-off, then experience: how it works, when you'd choose something else, and one time it mattered. Interviewers at L2 listen for whether you know the default you're relying on (a client's default timeout, a consumer's default commit mode) and why you'd change it.

**Where to spend time.** The communication part has the most L2 questions (69); HTTP clients, REST and gRPC lead. The [L2 learning path](../getting-started/index.md#learning-paths) covers the same chapters in a sensible order.
